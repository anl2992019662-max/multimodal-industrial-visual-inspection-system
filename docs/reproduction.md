# 安装、运行与复现

## 环境与资源

原工程环境为 Windows 上的 VisionPlus 4.2.3、VisionTrainPlus 1.0.0。版本来自本机安装信息，不代表最新版本或其他版本的兼容性承诺。软件与授权由使用者自行从权利方取得，本项目不提供商业软件二进制、破解文件或许可材料。

当前软件安装路径为 `D:\VisionPlus`。若你的路径不同，准备时增加 `--vision-plus-dir`：

```powershell
python tools/prepare.py --assets ../release-assets --destination runtime --vision-plus-dir C:/VisionPlus
```

`tools/prepare.py` 仅使用 Python 标准库。可先检查项目文件：

```powershell
python -m pip install -r requirements-dev.txt
python tools/verify.py
```

校验程序需要 lxml 解析包含较大模板数据的 XML；它不加载任何商业推理库。

## 两种资源恢复方式

| 用途 | 需要的配套 ZIP | 命令 |
|---|---|---|
| 用随附 12 张图检查默认工程 | `model-library.zip` | `python tools/prepare.py --assets ../release-assets --destination runtime` |
| 完整数据、训练项目与默认工程 | 所有资源 ZIP | 上述命令追加 `--with-dataset` |
| 仅查看配置，无模型 | 不需要 | `python tools/prepare.py --demo-only --destination runtime-inspection` |

完整恢复默认以硬链接将相同图片映射到原始数据集和各训练工程，节省重复空间。硬链接共享文件内容，请勿在这样的副本中覆盖原图；需要修改图片时使用 `--copy-data` 创建独立副本。准备工具从不覆盖已存在的目标目录，也不自动联网下载。

若文件系统或权限不支持硬链接，工具会自动复制。本次本地完整恢复使用了复制回退，并核对了全部 2,084 个图片路径的哈希。按独立副本计算，完整图片布局约 36.153 GB，另需模型与主工程空间；配套 ZIP 也请保留独立空间。

完整恢复后的原始数据在目标目录的 `dataset/`，训练图片在 `project/Model/**/images/`。默认运行输入仍指向随附的 12 张演示图；整集测试时请在平台中选择相应类别的实际图片文件夹，或建立单独的全幅测试输入目录，不要把包含多级子文件夹的根目录当作已经验证的输入。

路径绑定只作用于新生成的副本：4 个输入文件夹、已有模型引用、标定文件、HMI 标识与训练项目路径。原工程逻辑、启用状态、模型权重、阈值和标定数据保持原值。`preparation-report.json` 说明准备模式，不代表平台验收通过。

## 在 VisionPlus 内执行

1. 打开新副本的 `project/program1.5.vpsx`。如果平台提示缺少本机账户/授权设置，请按正版软件正常流程初始化；发布版不包含原账户数据库和工程保护配置。
2. 在设计视图核对四个采图工具的目录、5 个启用模型和棋盘格标定路径。采图方式保留为文件夹，按名称排序；相机设备接入不在本次工程复测范围内。
3. 检查 HMI 四个图像窗口、结果标签、运行/停止入口、“触发拍照”按钮和测量表。
4. 进入运行模式。触发后逐项记录输入文件名、模型版本、显示文字、X/Y 数值与是否报错。
5. 先逐项试验，再检查一次触发下的四任务更新。不要用数学脚本测试通过代替该步骤。
6. 保存新的运行截图和验收记录，不覆盖作者提供的历史截图。

## 验收记录模板

| 输入图像/哈希 | 预期类别/角度 | 实际结果 | X/Y 与判定 | 结果一致 | 备注 |
|---|---|---|---|---|---|
| 待填写 | 待填写 | 待运行 | 待运行 | 待核对 | 平台版本、模型哈希、拍摄条件 |

至少检查：极片五类缺陷与合格；线缆 0°、正负旋转及缺色；手套空模、破损与合格；芯片五类缺陷与合格；X/Y 公差内外边界；一次触发四项更新；运行/停止；图像完整显示。类别标注与数据切分应先人工核对，再形成混淆矩阵和每类指标。

芯片标准值是 X = 42.98 mm、Y = 1.56 mm，均为 ±1 mm。更换成像系统后要重新验证标定与基准方向，不能直接沿用当前结果宣称量测精度。

## 训练工程

完整恢复后，在 VisionTrainPlus 中打开各 `project/Model/**/Project.dls`。17 个项目的标注与划分文件保留；图像按恢复清单重建。项目元数据里的历史 precision/recall 等不能替代本机重新执行评估。

训练过程的临时权重、优化器状态和缓存不随包分发。因此可以检查数据、重新训练与评估，但没有承诺从原训练步数无缝续训。
